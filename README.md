# Macall Mensah portfolio

A static React and Vite website prepared for free hosting. The four supplied photographs are included under `public/photos`. The booking form opens WhatsApp; it does not store submissions.

## Run locally

`npm install` then `npm run dev`. For deployment, build with `npm run build` and publish `dist`. No API key is needed.

## Before publishing

Confirm Macall approves the text, photographs and booking phone number (+233 20 802 2554). Add real showreel, broadcast clips, client testimonials, and further social profiles only when supplied. Photo updates require replacing files under `public/photos` and redeploying.
